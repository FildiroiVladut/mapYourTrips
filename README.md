# Map Your Trips

Draw your walks, runs and bike rides on the map. Distance is measured from the route you draw, and pace, speed and your totals are calculated for you.

**Live demo:** https://fildiroivladut.github.io/mapYourTrips/

## Features

- Draw a route point by point, with live distance (undo, cancel, keyboard shortcuts)
- Walk, run and bike trips, each with its own colour on the map
- Automatic trip names from the start location (OpenStreetMap / Nominatim)
- Totals, filters by activity, and inline delete
- Trips saved in `localStorage`; light and dark theme; works on phones

Built with vanilla JavaScript (ES2022 classes and private fields) and [Leaflet](https://leafletjs.com). No build step: open `index.html` through any static server.
